# 个人主页

一个使用虚构人物“林知夏”和示例项目的中文个人主页。纯 HTML、CSS 与 JavaScript，可直接通过 GitHub Pages 发布，不需要构建步骤或第三方字体。

## 个性化

打开 `script.js` 修改姓名、简介、邮箱及链接；在 `index.html` 修改项目名称和说明。当前联系邮箱 `hello@example.com` 是示例地址。

## GitHub Pages 发布

创建一个名为 `personal-site` 的公开仓库并推送本目录内容，然后在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**、`main` 分支和 `/ (root)` 目录。保存后，网站地址会是 `https://Shawnlu-sy.github.io/personal-site/`。
